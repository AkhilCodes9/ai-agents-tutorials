# AI Research Agent 🤖

An AI-powered research assistant built with Python, LangChain, Google Gemini, and Pydantic.

The project demonstrates how to connect a large language model to a Python application and generate structured responses.

## Features

* 🤖 Google Gemini integration
* 🧠 LangChain agent framework
* 📋 Structured output using Pydantic
* 🔐 Environment variables for API key management
* 🐍 Python-based implementation

## Tech Stack

* Python
* LangChain
* Google Gemini
* Pydantic
* python-dotenv

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/AkhilCodes9/ai-agents-tutorials.git
cd ai-agents-tutorials
```

### 2. Create a virtual environment

```bash
python -m venv venv
```

Activate it on Windows:

```powershell
.\venv\Scripts\Activate.ps1
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Configure your API key

Create a `.env` file in the project directory:

```env
GOOGLE_API_KEY=your_google_api_key
```

Get your API key from [Google AI Studio](https://aistudio.google.com/).

### 5. Run the application

```bash
python main.py
```
